# 영상 스토리보드 양식

스토리보드는 영상을 **컷 순서대로** 미리 그린 설계도다. 컷 = 카메라가 끊기지 않는 한 덩어리. 사용자가 다른 양식을 말하면 그것을 따른다.

## 먼저 정할 것
- 제목, 총 길이, 화면비(기본 16:9), 한 줄 줄거리(시작 → 전개 → 끝)
- 등장 캐릭터. 캐릭터 보드가 있으면 `character_board.html`의 **그림 지시문 블록**을 찾아 그대로 쓴다.

## 컷 나누기
- 길이에 맞게 나눈다. 15초면 보통 4~7컷, 한 컷 1.5~5초. **컷 길이를 똑같이 나누지 않는다**(장면에 따라 짧게·길게).
- 샷 크기를 섞는다. 처음엔 넓게(상황 보여 주기) → 가까이(감정) 같은 흐름. 전부 미디엄 샷이면 안 된다.
- 생성 영상(클링 등)은 한 번에 5초·10초 단위로 만들어지므로, 짧은 컷은 생성한 영상에서 잘라 쓴다고 메모한다.

## 컷마다 칸
| 칸 | 쓰는 것 |
|---|---|
| 컷 | C01, C02 … · 짧은 제목 |
| 시간 | 시작–끝(00:00–00:03) · 길이 |
| 키프레임 | 컷이 시작되는 순간의 그림(16:9) |
| 화면 | 누가 무엇을 하는지, 무엇이 움직이는지 |
| 샷 | 샷 크기(롱·풀·미디엄·미디엄 클로즈업·클로즈업·익스트림 클로즈업) · 앵글(눈높이·하이·로우·버드아이) |
| 카메라 | 고정·팬·틸트·줌·돌리 인/아웃·트래킹·핸드헬드 |
| 소리 | 대사·내레이션 / 효과음 / 음악 |
| 자막 | 화면에 넣을 글자(없으면 비움) |
| 전환 | 컷·디졸브·페이드·매치컷 등 |
| 메모 | 짧은 한국어 메모·주의점(한두 줄). 영어 생성 지시문은 여기 넣지 않는다 |

행사 영상이면 컷마다 **큐(진행 신호: 예 "개막 선언 뒤 재생")** 칸을 더한다.

## 만들 것
- `storyboard/C01.png …`: 키프레임 그림, 1536x1024. 화면에서는 16:9로 잘라 보여 준다.
- `storyboard.html`: 인쇄할 수 있는 스토리보드 시트.
  - 맨 위 한 줄 머리말: 제목 · 총 길이 · 컷 수 · 한 줄 줄거리 · 캐릭터 썸네일(있으면)
  - 그 아래 **컷마다 한 행**: 왼쪽 키프레임(16:9), 오른쪽 위 칸 표(시간·샷·카메라·화면·소리·자막·전환·메모)
  - A4 가로로 인쇄하면 한 장에 2~3컷. 흰 바탕, 얇은 선, 칸 이름은 작고 내용은 읽기 쉽게.
  - 홍보 웹페이지 꾸밈(큰 색 띠, 알약 단추, 카드 그림자, 영어 장식 제목)은 쓰지 않는다.
  - 컷마다 쓴 영어 생성 지시문은 표가 무거워지지 않게 **맨 아래 '생성 지시문' 칸에 접어서(details)** 컷 번호별로 모은다.
- `storyboard.json`: 컷 번호·시간·길이·생성 지시문을 영상 생성과 편집에서 다시 쓰기 위한 표.

## 키프레임 그림 규칙
- 지시문 순서: **캐릭터 지시문 블록(글자 그대로) + 그림체 문장(글자 그대로)** → 장면 설명 → 샷 크기·앵글(영어로: wide shot, close-up, low angle …).
- 같은 장소는 장소 설명도 매 컷 같은 문장으로.
- 그림 안에 글자·자막·컷 번호를 넣지 않는다(자막은 표에 쓴다).

## 점검
- 컷 길이 합 = 총 길이
- 샷 크기가 섞였는가, 이야기가 시작–전개–끝으로 이어지는가
- 키프레임의 캐릭터가 캐릭터 보드와 같은가(다르면 그 컷만 다시 그린다)
