# Cloudflare 운영 안내

## 로그인과 저장

입장 화면의 **연수생 입장**에는 MDX 형식의 이용 코드를 넣습니다. **강사 입장**(`/instructor/login`)에는 기존 중계 서버의 별도 관리 인증값을 넣습니다. 강사는 `/instructor`에서 코드 조회·발급·중지 및 해당 코드의 작업실 입장을 할 수 있습니다. 코드 발급은 화면에서 개수·1인 한도·만료일을 정한 뒤 직접 실행합니다.

강사용 인증은 중계 서버의 `mudex.config.admin_secret_sha256`과 기존 `/admin/codes` API를 그대로 사용합니다. 입력값을 서버에서 검증한 뒤 AES-GCM으로 암호화한 1시간짜리 HttpOnly·Secure·SameSite=Strict 쿠키를 발급합니다. 관리 요청마다 중계 서버가 인증값을 다시 검증합니다. 강사용 값은 소스, localStorage 또는 평문 쿠키에 저장하지 않습니다.

강사 코드를 기존 중계 서버 `/status`로 검증한 뒤 7일짜리 HttpOnly·Secure 쿠키를 발급합니다. 코드로부터 HMAC으로 만든 작업공간 ID를 사용하므로 코드가 URL에 노출되지 않습니다. 코드마다 별도 Durable Object와 Container를 사용합니다. 코드 변경은 새 코드의 작업공간으로 이동합니다.

클라우드 로그인 서명 키는 Workers secret `SESSION_SECRET`입니다. 코드·토큰·파일은 브라우저 간에 공유되지 않습니다. 단, 같은 강사 코드를 공유하는 사람은 같은 사용자로 취급됩니다.

영구 데이터는 R2 `mudex-files`에 사용자별 경로로 보관합니다. 서버 시작 전에 복원하고, 변경 요청 응답·에이전트 완료·로그인 완료 전에 저장합니다. 서버가 실행 중이면 15초마다 추가 저장합니다. FFmpeg 임시 파일과 재생성할 수 있는 썸네일은 제외하고, 검수 시트는 저장합니다.

작업 이름 변경은 표시 이름만 바꾸고 기존 ID·파일·대화를 유지합니다. 작업 삭제는 실행 중인 작업/파일 요청을 확인한 뒤 저장 작업과 직렬화해 로컬 서버 파일과 R2 사본을 제거합니다. 작업마다 생성 UUID를 보관해, 이름이 같은 작업을 다시 만들어도 PC 백업과 섞이지 않습니다.

**PC 폴더 연결**은 File System Access API를 지원하는 데스크톱 브라우저에서 사용자가 직접 폴더를 선택·허용해야 합니다. 연결 핸들은 사용자 작업실과 작업 UUID별로 해당 브라우저 IndexedDB에 보관합니다. 파일 가져오기는 사용자가 선택한 미디어만 업로드합니다. **PC에 저장**은 선택 폴더의 `무덱스 저장/작업-해시/`에 `대화.md`, `작업.json`, 미디어를 저장합니다. 해시는 작업실과 작업 UUID를 함께 사용해 다른 작업실의 같은 이름 작업과 충돌하지 않게 합니다. PC 폴더가 클라우드 서버에 마운트되는 방식은 아니며 자동 감시·양방향 동기화를 하지 않습니다.

AI는 `list_mcp_connectors`, `search_mcp_tools`, `call_mcp_tool`로 연결된 전체 MCP 카탈로그를 탐색합니다. 수백 개 스키마를 매 요청에 전부 넣지 않고 필요한 스키마를 검색합니다. 알 수 없는 도구·다중 작업 도구·변경/비용/삭제/게시 도구는 인자 전체를 보여 주고 승인받습니다. 승인 토큰은 커넥터·도구·정규화된 전체 인자에 묶이며 5분 후 만료되고 한 번만 사용할 수 있습니다. 연결 해제 시 무효화하고, 결과가 불명확한 네트워크 오류로 효과 있는 호출을 자동 재실행하지 않습니다.

`import_higgsfield_media`는 로그인된 계정으로 완료된 기존 작업을 조회하고 결과를 `imported/`에 내려받습니다. 공개 HTTPS, DNS 주소 고정과 리디렉션 재검증, 알려진 미디어 MIME, 최대 16개/전체 2GB를 적용합니다. `.part`로 내려받은 뒤 완료 시 이름을 바꿔 불완전한 파일이 저장·표시되지 않게 합니다. 서비스가 다른 응답 형식이나 다운로드 형식을 반환하면 오류로 안내하며 임의 해석하지 않습니다.

서버 종료 시 신규 요청을 막고 진행 중인 요청·영상 작업을 확인한 뒤 파일 저장을 완료하고 Container를 종료합니다. Containers 디스크만으로 영구 보관하지 않습니다.

## 재배포

화면 또는 Worker 수정:

```sh
npm ci
npm test
npm run check:deploy
npm run deploy
```

`app/` 서버 코드를 수정한 경우 Linux 이미지도 새로 만들어야 합니다. Docker를 사용할 수 있는 환경에서:

```sh
docker build --platform linux/amd64 -t mudex:cloud-v7 .
npx wrangler containers push mudex:cloud-v7
```

출력된 이미지 주소로 `wrangler.jsonc`의 `containers[0].image`를 갱신한 뒤 `npm run deploy`를 실행합니다. 새 태그를 사용하십시오. 처음 이미지가 준비되거나 이미지가 바뀐 뒤에는 배포 명령이 끝나도 서버 이미지 적용에 시간이 걸릴 수 있습니다.

현재 이미지: `mudex:cloud-v6`. 실행 중인 서버에는 2시간의 배포 유예를 둡니다. 기존 화면에 **작업실 업데이트**가 보이면 작업을 마친 뒤 눌러 저장·재시작할 수 있습니다. 이 요청은 진행 중인 작업과 파일 요청이 있으면 거절하며, 입장 쿠키와 작업 선택을 유지합니다.

```sh
npx wrangler whoami
npx wrangler containers list
npx wrangler containers instances a03eb806-9311-4d25-a8a6-1861f520ee3a
npx wrangler tail
```

이 PC의 최초 이미지는 Docker 서비스 설치 없이 `crane`으로 공식 Node 이미지에 FFmpeg와 앱 파일 레이어를 추가해서 만들었습니다. 기반 이미지의 SHA256은 Dockerfile에 고정했습니다. 저장소에는 사용자 파일·로컬 서명 키·임시 레지스트리 자격증명을 포함하지 않습니다.

- 로컬 실행 HTTP 200 유지
- 공개 앱: 잘못된 코드 거절, 로그인 없는 API 거절
- 실제 Containers: 1초 MP4 업로드 → ffprobe 길이·해상도 측정 → FFmpeg 썸네일 생성
- 다른 사용자의 파일 URL 접근 404
- 서버 프로세스 ID가 달라지는 완전 종료·재시작 뒤 R2 영상 바이트 일치 및 썸네일 재생성 확인
- 힉스필드 실제 OAuth 동적 등록 및 공개 HTTPS 콜백 주소 수락 확인. 사용자 계정으로 로그인 완료하거나 유료 영상 생성은 하지 않았습니다.
- 데스크톱 1440×1000, 모바일 390×844 화면 검토. 작은 화면의 작업·계정 및 파일·미리보기 메뉴 접근 확인
- 강사 전용 입장과 기존 코드 6개 조회를 실제 인증으로 확인. 한도 소진 코드는 사용 가능 집계·일괄 복사에서 제외하며, HTML·SVG 등 사용자 업로드는 첨부파일 다운로드와 sandbox 정책으로 강사 권한 스크립트 실행을 차단합니다.

모델 대화·유료 영상 생성의 실제 실행에는 유효한 강사 코드와 사용자의 힉스필드 로그인이 필요합니다. 이번 배포 점검에서는 생성 비용을 사용하지 않았습니다.
